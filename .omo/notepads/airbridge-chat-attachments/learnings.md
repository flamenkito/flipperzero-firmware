## Phase 0 protocol module

- Existing `web/sender.html` and `web/receiver.html` use a 5-byte header: type(1), seq(2 big-endian), len(2 big-endian), followed by up to 59 payload bytes.
- META fragmentation format is preserved exactly: every META payload starts with a 2-byte big-endian total fragment count, followed by that frame's JSON byte slice.
- ACK frames carry the acknowledged sequence in payload bytes 0..1, independent of the ACK frame's own sequence field.
- `web/airbridge-protocol.js` is transport-neutral: callers provide send callbacks and feed inbound ACKs/messages from WebHID, Web Bluetooth, or a test harness.
